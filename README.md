**Explainable AI with Human-in-the-Loop Feedback for Real-Time Fraud Detection in Nigerian Inter-Bank Payment Systems**

A fraud detection framework that explains each decision with SHAP and learns from analyst feedback. It was evaluated on synthetic transaction data, with the feedback loop simulated.
